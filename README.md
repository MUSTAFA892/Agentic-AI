# AI Agent-based Application

This project leverages the **Phi AI platform** to create intelligent agents that can assist with various tasks, such as generating jokes, providing study explanations, and more.

## Features:
- **Joke Generator**: Get a variety of jokes, including programming, miscellaneous, and dark humor, all generated by AI.
- **Study Assistance**: Receive detailed explanations on specific topics to aid in studying.

## Core Technologies Used:

1. **Groq**:
   - **Groq** is an advanced AI model used to process and generate human-like responses to various prompts. It enables the intelligent agents in this application to interpret complex user inputs and provide relevant, dynamic responses. We use **Groq** to power tasks such as text generation, information retrieval, and more.

2. **PhiDara**:
   - **PhiDara** is the underlying agent framework of the **Phi platform**. It enables the creation, management, and coordination of AI agents for performing specific tasks. With **PhiDara**, we can deploy multiple agents, each specialized in a task like generating jokes, providing study help, or conducting web searches. The agents work together seamlessly to provide the user with an enhanced experience.

## Setup Instructions:

1. **Clone the Repository**:
   - Download or clone the project to your local machine.

2. **Set Up Virtual Environment**:
   - Create a virtual environment to manage dependencies:
     ```bash
     python -m venv venv
     ```
   - Activate the environment:
     - On **Windows**: `venv\Scripts\activate`
     - On **Mac/Linux**: `source venv/bin/activate`

3. **Install Dependencies**:
   - Install the necessary Python libraries using:
     ```bash
     pip install -r requirements.txt
     ```

4. **Run the Application**:
   - Run the script that activates the AI agents, and interact with them for tasks like joke generation or study help.

## Prerequisites:
- **Python 3.x**
- An active internet connection for fetching data from APIs and interacting with AI agents.

## What It Does:
- Generates random jokes based on different categories.
- Provides explanations and study material for specific topics.
